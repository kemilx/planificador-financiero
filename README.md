# Mi Balance

Planificador financiero personal para administrar ingresos quincenales, pagos fijos, gastos y metas de ahorro en pesos dominicanos.

## Funciones

- Resumen mensual y disponible por quincena.
- Ingresos y pagos recurrentes por fecha.
- Seguimiento de gastos y ahorros realizados.
- Cierre mensual automático.
- Proyección de ahorro a 3, 6, 9 y 12 meses.
- Calendario financiero.
- Exportación e importación de respaldos.

Los datos se guardan únicamente en el navegador del dispositivo.

## Ejecutar localmente

```bash
npm install
npm run dev
```

## Verificaciones

```bash
npm run lint
npm run build
```
